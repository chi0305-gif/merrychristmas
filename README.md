# SWSH Christmas Reading Quest
四維高中圖書館聖誕週：《聖誕故事失竊事件：DeDe 的最後任務》手機閱讀闖關遊戲。

純靜態網頁，不需安裝 APP、不需註冊、不需伺服器、**不需掃 QR Code**。

| 檔案 | 用途 |
|---|---|
| `index.html` | 遊戲原始檔（首頁 → 序章 → 冒險地圖 → 五關 → 完整故事 → 完賽證書） |
| `config.js` | 活動設定：關卡名稱、建議地點、通關字、核銷 PIN、驗證碼鹽值 |
| `dist/dede-quest.html` / `.txt` | 由 `python3 build.py` 合併出的單一檔案（內容相同），直接上傳即可 |

## 遊戲流程
1. 學生打開網址 → 閱讀序章 → 輸入小隊暱稱（不收個資），開始計時。
2. 在冒險地圖上依序闖關：完成一關，下一關才會打開。每關附「建議地點」，可搭配實體佈置與書展。
3. 五關互動：拆信閱讀理解／雪人詞語排序／翻線索卡從書架抽書／聖誕球數字密碼／DeDe 禮物盒開鎖。
4. 每關取得一個通關字（暖、愛、讀、閱、心）、一章故事碎片與一本延伸閱讀推薦書。
5. 完成後閱讀完整聖誕故事，取得探險家證書（可下載證書圖片）。
6. 工作人員在證書頁輸入 PIN 核銷，證書蓋上「已兌換」章。
