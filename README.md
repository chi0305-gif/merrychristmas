# SWSH Christmas Reading Quest
四維高中圖書館聖誕週：《聖誕故事失竊事件：DeDe 的最後任務》手機實境閱讀遊戲。

純靜態網頁（HTML + CSS + JavaScript），不需安裝 APP、不需註冊、不需伺服器。

| 檔案 | 用途 |
|---|---|
| `index.html` | 學生用的遊戲網頁（首頁 → 序章 → 冒險地圖 → 五關 → 完整故事 → 完賽證書） |
| `staff.html` | 工作人員後台：產生並列印 6 張 QR Code 立牌、核對完賽驗證碼 |
| `config.js` | 活動設定：地點、QR 網址代號、備用地點代碼、核銷 PIN、驗證碼鹽值 |

## 遊戲流程
1. 學生掃描入口 QR Code → 閱讀序章 → 輸入小隊名稱（不收個資），開始計時。
2. 到每個據點掃描該關 QR Code（網址 `index.html#go-xxxx`）才能打開關卡；掃不到可輸入立牌上的 4 位數地點代碼。
3. 五關互動：
   - 第一關「聖誕信件」：點封蠟拆信 → 閱讀理解題
   - 第二關「雪人拼圖」：點選詞語排成句子 → 核心價值題
   - 第三關「神祕書單」：依序翻線索卡 → 從書架抽出正確的書（翻越少張分數越高）
   - 第四關「密碼研究所」：數字轉字母，用聖誕球密碼與螢幕鍵盤作答 READ
   - 第五關「DeDe 終極任務」：集滿前四個通關字才開放；選出精神句 → 依序放入通關字開鎖 → 禮物盒打開
4. 每關獲得一片「故事碎片」（故事的一章）＋一本延伸閱讀推薦書，收進「故事收藏冊」。
5. 完成後閱讀完整的聖誕故事，取得探險家證書（含完成時間、雪花數、5 碼驗證碼）。
6. 工作人員在證書頁輸入 PIN 核銷，證書蓋上「已兌換」章。

答錯時 DeDe 會給逐步提示，不會卡關；每關依答錯次數得到 1–3 顆雪花。

## 上線步驟（GitHub Pages）
1. 把三個檔案推到 GitHub，在 repo 的 Settings → Pages 選擇分支發布。
2. **先改 `config.js` 的 `staffPin` 與 `salt`**，也可以改每關的 `key`／`code`／地點名稱。
3. 開啟 `https://<網址>/staff.html`，確認網址後按「產生立牌」→ 列印。
4. 測試：網址加上 `#demo` 會解鎖全部關卡（畫面左下角顯示「測試模式」），測完在收藏冊按「清除進度」。

## 驗證碼與防作弊說明
- 進度存在學生手機瀏覽器（localStorage），不需要伺服器。
- 驗證碼 = 雜湊(小隊名稱 + 完賽時刻 + 鹽值)，工作人員可在 `staff.html` 核對，防止改圖或亂填。
- 限制：純前端無法完全防止同一組換手機重玩、或拿別組的手機重複兌換。若需要「一組只能兌換一次」與後台統計（參加組數、各關完成率），下一步可接 Firebase / Supabase 或 Google Sheets。
